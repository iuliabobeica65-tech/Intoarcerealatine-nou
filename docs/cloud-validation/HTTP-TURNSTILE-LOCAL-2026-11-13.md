## Protecții și comportament

- Profilul HTTP este separat și implicit oprit. VALIDATION_ACTIVE și VALIDATION_HTTP_REGISTRATIONS rămân false în configurația pregătită. Pentru viitoarea fereastră autorizată sunt obligatorii un marcaj nou, identitatea D1, secretul/sitekey Turnstile dedicate și expirarea server-side în maximum o oră. După expirare Worker-ul refuză inclusiv API-ul, indiferent de browser. Expirarea nu ține locul curățării finale a configurației.
- Access principal/wildcard rămâne obligatoriu. Verificarea JWT RS256/AUD/issuer/identitate rămâne în cod; fiecare API cere și Bearer administrativ, POST JSON, Origin exact și marcajul bazei cu scopul corect. Root și alte origini sunt refuzate. Nu există rută publică de bypass.
- /api/register este permis numai în acest profil autentificat, pentru adrese strict `@example.invalid`, offeringId prefixat `validation-` și evenimente gratuite. Codul real de înscriere, verificarea Turnstile, rate limit, capacitate, duplicate și outbox sunt reutilizate. Override-ul TEST_MODE=false este local numai acelei cereri sintetice /api/register, după toate porțile de autorizare; nu se transmite abonării și nu relaxează destinatarul DOI.
- /api/validation/config este POST autentificat și returnează doar cheia publică Turnstile, expirarea și faptul că datele sunt sintetice/expedierea oprită. Niciun secret nu este returnat. Evenimentele comerciale, modificarea ofertelor/lifecycle prin acest profil, newsletter, checkout, webhook Stripe și dispatch sunt refuzate.
- Brevo/Stripe/SmartBill secrets provoacă refuzul configurației. EMAIL_SEND_ENABLED și toate flagurile comerciale sunt obligatoriu false. Mesajele de eveniment pot fi pregătite în coadă, dar nu sunt expediate. Profilul nu activează automatizări.
- CSP permite script/frame/connect numai self și challenges.cloudflare.com pentru Turnstile; noindex,nofollow,noarchive și no-store sunt adăugate răspunsurilor Worker. Codul administrativ este păstrat numai în memoria paginii, fără URL/storage; inputul este golit. Tokenul primit la înscriere nu este afișat/stocat de UI.
